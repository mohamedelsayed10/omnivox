# OmniVox Quick Facts

## Languages
OmniVox understands spoken English and Arabic. The language is detected automatically from the caller's voice, so no setting is needed.

## Onboarding
Every new customer gets a free setup call during the first week. The call covers connecting phone numbers, uploading documents and choosing a voice.

## Security
Documents are stored in your own database and are never shared. Call recordings can be turned off for any agent.
